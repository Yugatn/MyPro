# MPOP: оценивание психометрической кривой v0.2

## Назначение

Этот этап описывает и реализует оценивание параметров логистической психометрической кривой по агрегированным trial-level результатам. Это исследовательский прототип, а не валидированная модель восприятия. Перед анализом необходимо заранее определить задачу, стимулы, критерий успеха, правила исключения, единицу анализа и план неопределённости.

## Модель

Для длительности предъявления t используется:

p(t) = g + (1 − g − λ) / (1 + exp(−k(t − μ)))

где g — вероятность угадывания/нижняя асимптота, λ — lapse rate, k > 0 — наклон, μ — середина между асимптотами. Параметр μ не равен автоматически порогу 50% правильных ответов, если g ненулевой.

## Оценивание

- Использовать биномиальное правдоподобие для количества правильных ответов и числа испытаний на каждой длительности.
- Параметры ограничивать физически и статистически допустимыми диапазонами; фиксированные и оцениваемые параметры явно указывать.
- Проверять сходимость, границы параметров и идентифицируемость. Плоская кривая или отсутствие разнообразия ответов может не позволить оценить порог.
- Не смешивать повторные испытания одного участника с независимыми участниками без учёта кластеризации.
- Для неопределённости предпочитать bootstrap на уровне участника, профиль правдоподобия или заранее обоснованный байесовский метод; обычный bootstrap отдельных trials может занижать неопределённость при повторных измерениях.
- Публиковать критерий порога и интервал неопределённости; не скрывать неудачные подгонки.

## Ограничения текущей реализации

Существующий `core/analysis/psychometric.py` предоставляет вычисление заданной кривой и её обратное преобразование. Он не подгоняет параметры и не вычисляет доверительные интервалы. Следующий шаг реализации должен добавить отдельный модуль подгонки с диагностикой и тестами на синтетических данных с известными параметрами.

## Запреты интерпретации

Экспозиция не доказывает обнаружение. Обнаружение не доказывает запоминание. Запоминание не доказывает отношение или изменение поведения. Порог относится только к конкретной задаче, стимулу, выборке, условиям и заранее заданному критерию.
