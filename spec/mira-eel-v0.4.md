# «Мира» v0.4 — EEL and Measurable Dynamics

## 1. State space

Пусть состояние ω имеет вид:

ω = (G_net, A_adv, NES, G_σ, Ψ, B_RIP, θ_MCL, R)

где компоненты описывают сетевое состояние, поле возмущений, состояния агентов, граф совместимости, correspondence maps, бюджет RIP, рабочие параметры и допустимый семантический регион.

Ω — множество допустимых конфигураций ω.

Важно: Ω — не множество событий. Это пространство состояний.

## 2. Measurable structure

FΩ = σ(Z) — σ-алгебра, порождённая выбранным набором наблюдаемых величин Z:

- Π_H;
- Φ;
- Ψ;
- D_e;
- λ₂(G_σ) для связности;
- H(σ);
- B_RIP;
- режимные индикаторы.

Для ненормированного графового лапласиана предпочтительно использовать λ₂ как алгебраическую связность. Для directed/weighted графов должна быть явно указана используемая спектральная мера.

## 3. Dynamics

Динамика задаётся вероятностным переходным ядром:

K(ω, E) = P(S_{t+1} ∈ E | S_t = ω)

для каждого E ∈ FΩ.

Требование замкнутости:

ω ↦ K(ω,E) измерима для каждого E ∈ FΩ.

Это минимальное условие корректной вероятностной динамики.

## 4. Invariant measure

Вероятностная мера μ называется инвариантной, если:

μ(E) = ∫Ω K(ω,E) dμ(ω)

для всех E ∈ FΩ.

Эргодичность не следует автоматически из существования μ. Для эргодичности дополнительно требуется отсутствие нетривиального инвариантного разбиения в рассматриваемом классе динамики.

Поэтому connectivity, plurality и grounding трактуются как ограничения устойчивой области, а не как уже доказанная теорема существования меры.

## 5. Perturbation Budget Law

Пусть B_t ≥ 0 — запас восстановления.

Обобщённая динамика:

B_{t+1} = clip(B_t + ρ(C_ISCL) - c(q_t), 0, B_max)

где:

- ρ — скорость восстановления;
- C_ISCL — измеряемая связность/совместимость;
- q_t — интенсивность RIP;
- c(q) — стоимость возмущения.

RIP разрешён только при:

B_t ≥ B_min.

При B_t < B_min система переходит в recovery mode.

## 6. Reality Injection Protocol

RIP не должен буквально «делать D_e максимальным». Для вычислимой системы корректнее считать его контролируемым сбросом prior-dependent correspondence для выбранного якоря.

Для якоря i:

1. временно исключается соответствующий prior;
2. выполняется независимая оценка по сырому наблюдаемому набору O_i;
3. строится новая Ψ_i';
4. измеряется Δ_i = dist(Ψ_i', Ψ_i);
5. обновляются D_e, RIC и бюджет.

Так RIP становится воспроизводимым экспериментом, а не метафорической «шоковой терапией».

## 7. Stability region

Определим:

M_stable = {ω ∈ Ω : λ₂(G_σ) > λ_min, H(σ) > H_min, G(ω) = 1}

где G(ω)=1 означает наличие требуемого уровня grounding.

Это множество проектных ограничений, а не автоматически доказанная теорема устойчивости.

## 8. Phase classification

Режимы определяются измеримыми областями:

- Stable Tension — все ограничения выполняются;
- Pre-Dogmatic Contraction — H(σ) приближается к границе;
- Silent Semantic Drift — D_e имеет устойчивый положительный тренд;
- Epistemic Fragmentation — λ₂(G_σ) приближается к нулю.

Переход между режимами должен использовать hysteresis/debounce policy, чтобы шум не создавал ложных фазовых переходов.

## 9. Verification programme

Следующий вычислимый этап — не добавление нового архитектурного слоя, а verification suite:

1. проверить измеримость всех переходов;
2. проверить сохранение Ω под каждым оператором;
3. проверить бюджет RIP;
4. оценить существование/единственность инвариантных мер на конечных и дискретизированных моделях;
5. измерить время восстановления после RIP;
6. проверить переходы между четырьмя фазовыми режимами;
7. провести adversarial tests для CGPF/UACL/EAL/ISCL.

## 10. Evidence status

- DERIVED: переход от fixed-point к invariant-measure framing после введения RIP.
- DERIVED: необходимость measurable transition kernel для строгой вероятностной динамики.
- CLAIMED: connectivity + plurality + grounding достаточны для практической устойчивости. Требуется проверка.
- NOT_TESTED: существование и единственность инвариантной меры полной системы.
- NOT_TESTED: эргодичность полной системы.
- NOT_TESTED: масштабируемость UACL/RIP.
- CONFLICTED: буквальная интерпретация «голографического транспорта» как физической голографии; инженерно это следует трактовать как избыточное/фрагментированное кодирование.

## 11. Research rule

«Мира» не должна подтверждать собственную теорию только внутренними метриками. Любое утверждение об устойчивости получает статус DERIVED только после воспроизводимого эксперимента или формального доказательства; до этого — CLAIMED или NOT_TESTED.
