# MyPro

**MyPro** — открытая платформа для интеллектуального видеомонтажа и связанной с ним экосистемы.

Главная идея: автор описывает замысел ролика, система анализирует исходные материалы и предлагает редактируемую структуру монтажа. Человек сохраняет контроль над каждым существенным решением.

Проект начинается с малого: сначала создаём устойчивую модель проекта и монтажа, анализируем медиа и строим минимальный воспроизводимый pipeline. UI, мобильное приложение, камера РосЭкшн, магазин и расширенный SDK подключаются постепенно.

## Цели первого этапа

1. Определить машинно-читаемую модель монтажа.
2. Научиться получать технические метаданные через FFprobe.
3. Подготовить единый media manifest.
4. Заложить интерфейсы анализа сцен, речи и содержания.
5. Поддержать импорт и экспорт через OpenTimelineIO.
6. Добавить минимальные тесты и проверки целостности.

## Архитектурный принцип

AI не должен владеть проектом монтажа напрямую. AI создаёт предложения и метаданные, а Montage Model остаётся источником истины для редактируемого проекта.

Базовый контур:

**Media → Analysis → Montage Model → Human Editing → Render / Export**

Формальное описание границ компонентов находится в docs/ARCHITECTURE.md.

## Структура

- core/ — независимое ядро проекта.
- ai/ — анализ и AI-функции.
- apps/ — пользовательские приложения.
- integrations/ — внешние форматы и движки.
- sdk/ — будущий API расширений.
- tests/ — тесты и инварианты.
- docs/ — архитектурная документация.
- tools/ — утилиты разработчика.

## Статус

Проект находится на стадии архитектурного основания.

Все характеристики будущего оборудования, производительности, стоимости, сервисов и коммерческих тарифов являются проектными гипотезами, пока не подтверждены прототипами и испытаниями.
