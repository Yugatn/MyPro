# Privacy

MyPro is designed around local-first processing.

Principles:

1. Minimize data collection.
2. Prefer on-device analysis when practical.
3. Make network use explicit.
4. Keep sensitive analysis results scoped to the project.
5. Support redaction and anonymization workflows.
6. Record consent or policy metadata when a workflow requires it.
7. Do not silently classify a person as a sensitive category.

Privacy controls are implemented as project and capability policies, not as a claim that every future plugin is privacy-preserving.
