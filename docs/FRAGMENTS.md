# MyPro Content Fragments

A ContentFragment is a reusable reference to a time range in source media. It is not a copied media file and it is not automatically a conclusion about the content.

## Kinds

Fragments may represent media ranges, scenes, speech, actions, reactions, people, objects, sounds, semantic segments, or composites.

## Provenance

Every fragment records source content identity, a source hash, exact rational time, and, when generated by an analyzer, observation identifiers and detector version. Confidence and uncertainty are explicit when available.

## Reuse

A fragment can be referenced by multiple editorial projects. A montage stores the editorial use of the fragment separately from the source fragment, allowing the same material to be reused for clips, trailers, short videos, documentaries, or feature-length edits without duplicating the source payload.

## Proposals

Analyzers and AI may produce FragmentProposal objects. A proposal is not an action. Accepting a proposal belongs to the project decision and action layer.

## Core invariants

- exact rational time is used
- source identity is mandatory
- uncertainty is visible when available
- composite fragments explicitly identify their parents
- duplicate fragment identifiers are rejected by the index
- fragments do not silently replace source media
- proposals do not mutate fragments
