# Glossary

**Asset** — identifiable media or derived artifact.

**Observation** — measured or detected information with status, uncertainty and provenance.

**Interpretation** — model-based meaning assigned to observations.

**Finding** — aggregated, reviewable conclusion.

**Hypothesis** — testable proposition.

**Proposal** — suggested change from AI or a plugin.

**Decision** — explicit human or policy choice.

**Action** — applied project mutation.

**Revision** — recoverable project state.

**Provenance** — record of derivation and inputs.

**Capability** — technical authority granted to a component.

**Policy** — rule governing whether an operation is allowed.

**Evidence** — traceable set of artifacts and derivations supporting a result.
